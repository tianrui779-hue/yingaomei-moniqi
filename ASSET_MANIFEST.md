# Asset Manifest

Codex must always use exact file paths from `ASSET_MANIFEST.md`.

Codex must not guess from pasted images or vague references like "the previous image".

If an asset is missing, use a graceful CSS fallback and do not break the game.

## Asset Folders

- `assets/backgrounds/` stores scene backgrounds.
- `assets/items/` stores inventory item icons.
- `assets/ui/` stores HUD and interface images.
- `assets/characters/` stores character images.
- `assets/effects/` stores visual effect images.
