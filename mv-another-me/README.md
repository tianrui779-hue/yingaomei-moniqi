# 世界上的另一个我 · painted MV

A ~58 s hand-painted lyric MV for 《世界上的另一个我》 (阿肆 / 郭采洁), in the style of the
[painted-animation](https://github.com/tuzhechen2005/painted-animation) skill (p5.js + p5.brush watercolour, boiling ink
lines, Ma Shan Zheng karaoke). Every frame is drawn in code; nothing is generated by an image model.

- **Video:** `世界上的另一个我_MV.mp4` (1920×1080, 24 fps, **no audio yet**, see below)
- **Storyboard:** [STORYBOARD.md](STORYBOARD.md)
- **Scenes:** `src/scenes/ot_set.js` (song grid, cast, cities, props), `ot_verse.js` (bars 0–8), `ot_chorus.js` (bars 9–21),
  karaoke in `src/karaoke.js`

## Syncing to the song

The song file and its LRC couldn't be fetched in the build session, so the video is cut to an **assumed grid: 92 BPM,
one lyric line per bar** (≈ 2.61 s). Every hit (fireworks, the wave, the season changes, the clock snap, each "啦") sits
on `bar(n)` + beats, so re-syncing is a config change, not a re-animation:

1. Put the song in `assets/song.mp3` and measure it (needs numpy):
   `python3 beat_grid.py assets/song.mp3 --lrc=song.lrc`
2. Cut the clip: verse 1 + verse 2, then the chorus, starting one bar before 「上一秒我在台北看烟火」 (the pre-chorus
   「人生到处是假正经…」 is skipped with a splice on a bar line), and save it as `assets/clip.m4a`.
3. In `src/config.js` set `bpm` to the measured tempo (and `offset` if the clip's first downbeat isn't at 0). If a line
   isn't exactly one bar long, change its bar count in `LINES` (`src/scenes/ot_set.js`).
4. Re-render with the audio:
   ```bash
   npm install
   ./rs.sh --frames --workers=1          # or: node render.mjs --frames  (on a machine with a GPU, drop rs.sh's --soft-gl)
   ./rs.sh --encode --audio=assets/clip.m4a --out=out/video.mp4
   ```

## Checking frames

```bash
./rs.sh --sheet=3,6,9 --cols=3 --w=480 --out=out/check/a.jpg     # contact sheet at chosen times
./rs.sh --strip=24:25 --out=out/check/strip.jpg                   # every frame of a moment
```

`rs.sh` runs `render.mjs` with software WebGL and the Playwright Chromium. Two settings in `src/config.js` keep that
fast enough on a GPU-less machine: `fastFill` (translucent washes in place of p5.brush's watercolour fills) and
`density: .6667` (the paint layer renders at 1280×720 and is scaled to 1080p). On a machine with a GPU, set
`fastFill: false, density: 1` for the full-quality watercolour.
