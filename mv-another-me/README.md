# 世界上的另一个我 · painted MV

A 64 s hand-painted lyric MV for 《世界上的另一个我》 (阿肆 / 郭采洁), in the style of the
[painted-animation](https://github.com/tuzhechen2005/painted-animation) skill (p5.js + p5.brush watercolour, boiling ink
lines, Ma Shan Zheng karaoke). Every frame is drawn in code; nothing is generated by an image model.

- **Video:** `世界上的另一个我_MV.mp4` (1920×1080, 24 fps, 64 s, with the song)
- **Storyboard:** [STORYBOARD.md](STORYBOARD.md)
- **Scenes:** `src/scenes/ot_set.js` (song grid, cast, cities, props), `ot_verse.js` (bars 0–8), `ot_chorus.js` (bars 9–21),
  karaoke in `src/karaoke.js`

## The song and the sync

The audio is cut from a recording of the song the user supplied: tempo measured at 132.5 BPM, each lyric line's start
found from the vocal track (separated with Spleeter). The clip skips the pre-chorus with a beat-aligned cut; details are
in [STORYBOARD.md](STORYBOARD.md). Shot cuts and karaoke timings live in `CUTS` and `LINES` in `src/scenes/ot_set.js`
(in song seconds), so a line can be nudged by editing one number.

To rebuild (the clip itself isn't in git; recreate `assets/clip.m4a` from the song as described in the storyboard):

```bash
npm install
./rs.sh --frames --workers=1
./rs.sh --encode --audio=assets/clip.m4a --out=out/video.mp4
```

## Checking frames

```bash
./rs.sh --sheet=3,6,9 --cols=3 --w=480 --out=out/check/a.jpg     # contact sheet at chosen times
./rs.sh --strip=24:25 --out=out/check/strip.jpg                   # every frame of a moment
```

`rs.sh` runs `render.mjs` with software WebGL and the Playwright Chromium. Two settings in `src/config.js` keep that
fast enough on a GPU-less machine: `fastFill` (translucent washes in place of p5.brush's watercolour fills) and
`density: .5` (the paint layer renders at 960×540 and is scaled to 1080p; karaoke stays full-resolution). On a machine with a GPU, set
`fastFill: false, density: 1` for the full-quality watercolour.
